    Each request goes to these external approvers in order, then to a final administrator. The final step is always an authenticated administrator and cannot be removed or reassigned. External approvers need no account: they confirm their identity with a one-time code sent to the address below.

    Email delivery

    Message text is never shown here: it can contain one-time codes and approval links. A failed message that held a one-time code cannot be sent again; the approver asks for a new code on the approval page.

    Consistency check

    Compares seats, stubs, room holds and approval links with each other. It only reads. Repairs are run by an operator with npm run reconcile.
